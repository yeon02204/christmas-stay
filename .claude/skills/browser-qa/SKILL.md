# browser-qa — 브라우저 확인

전제: Playwright MCP 연결(`/mcp` 에서 playwright 확인). 개발 서버는 사용자가 띄워 둔 `http://localhost:5173` (없으면 실행을 요청).
배포 확인이면 사용자가 알려준 Vercel 주소 사용.

## 로그인
비밀번호를 묻거나 입력하지 마. 브라우저를 열고 **사용자에게 직접 로그인해 달라고** 요청한 뒤 기다려.

## 데이터 원칙
- 실서비스 DB 다. 테스트용 숙소를 만들어야 하면 먼저 사용자에게 허락을 받고, 이름을 `[테스트] ...` 로 시작하게 하고, 끝나면 삭제해.
- 기존 숙소·객실은 수정/삭제하지 마 (보기만).

## 기본 점검 (읽기 전용)
각 화면을 1280×900, 390×844 두 크기로:
1. 홈 `/` — 카드, 검색·필터·정렬 동작
2. 숙소 상세 → 객실 상세 — 갤러리 넘기기, 총비용 계산기 체크박스
3. 비교 `/compare` — 표 표시, 모바일 가로 스크롤
4. 찜 `/favorites`
5. 숙소 등록 폼 `/stays/new` — 입력 후 **저장하지 말고** 다른 메뉴 클릭 → 이탈 확인창 → "계속 입력하기"

각 단계마다 확인:
- `document.documentElement.scrollWidth > innerWidth` 이면 가로 넘침 (비교표 내부 스크롤 제외)
- 콘솔 error / 실패한 네트워크 요청
- 하단 내비·저장 바가 버튼을 가리는지
- 이미지 깨짐("사진을 불러올 수 없어")

## 보고
화면별 표: `화면 | PC | 모바일 | 문제`. 문제마다 스크린샷 근거와 고칠 파일을 제안해. 직접 고쳤다면 다시 찍어서 전/후를 비교해.
